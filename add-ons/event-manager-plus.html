Event Manager Plus

Club · / year (see Pricing for multi-year)

Everything in Event Manager, stretched over several days: practice, qualifying, heats, finals, enduro — with carry-over rules between sessions and optional sanctioned lock.

Who it’s for. Organisers of multi-day meetings and sanctioned nationals with carry-over to the finals.

Features

  • ✓Multi-day — first day + how many days; stage chain in fixed order
  • ✓Carry-over between sessions into the finals
  • ✓Vet & start on day 1; late joiners enter only sessions open to everyone
  • ✓Sanctioned mode — race procedure locked to the template
  • ✓Example national templates marked as examples from public rules — check the current body rules before an event
  • ✓Includes Event Manager on the licence card

Extra Track

Club · / year (see Pricing for multi-year)

Club licenses one track per key. Each Extra Track add-on licenses one more on that same computer. Set up and test any number of tracks; only licensed tracks can start a race.

Who it’s for. Clubs with more than one physical track driven from the same APEX computer.

Features

  • ✓One Extra Track licence = one additional licensed track on this computer
  • ✓Each track keeps its own lap counter, wiring, clock correction and part-lap learning
  • ✓Licensed track name and lane count are fixed by the key
  • ✓Unlicensed tracks show Not licensed and cannot race
